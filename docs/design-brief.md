# 원두 알림 유료 파일럿 — 기존 화면 확장

범위: 공개 `/premium`, `/settings/alerts`, 홈페이지의 작은 상품 진입 링크. 기존 Next 앱의 어두운 커피 색상, Noto Sans KR/Playfair, coffee-gold/coffee-light/coffee-latte 토큰, 44px 액션 높이를 재사용한다. 신규 브랜드나 전체 홈페이지 개편은 하지 않는다.

## 사용자와 결정

관심 원두를 여러 로스터리에서 확인하는 사용자. 공개 안내의 과제는 '무엇을 얼마나 자주 알려주며 유료 차이가 무엇인지 이해하기', 주 행동은 무료 알림 연결이다. 설정의 과제는 '현재 내 연결/이용권 상태에서 다음 행동하기', 주 행동은 상태에 따라 로그인/연결/신청/상태확인/원두선택 중 하나다.

공개 첫 화면은 제목과 가치, 가격과 무료 차이, 주 행동과 준비 안내의 3그룹이다. 설정 첫 화면은 제목, 현재 상태와 주 행동, 가격·상품 안내의 3그룹이다. 확인 범위와 제한/연결 관리는 details 뒤로 미룬다. 불필요한 신규 지표·카드 나열·이모지를 추가하지 않는다. Lucide Bell/Link2/ArrowRight는 장식이면 aria-hidden 처리한다.

## 상태와 상품 정합성

- 로그인 전에도 `/premium`의 상품 설명·2,900원/30일·자동결제 없음이 보인다.
- 로딩: 상태 확인 중 텍스트와 비활성 주 동선. 오류: 오류 설명과 재확인 행동.
- 미연동: 연결 행동 하나. 코드 발급 후 Telegram deep link로 전환한다.
- 유료 준비 미확인: 무료 연결/원두 선택을 유지한다. 미확인 결제 조건을 만들지 않는다.
- pending/awaiting_payment: 결제 완료로 보이지 않는다. 접수/안내 상태와 확인 행동.
- active: 실제 만료 시각 KST와 연장 신청. expired: 무료 3개로 전환됨과 접수 가능 시 연장.
- manual/invalid: 기존 수동권한 또는 기간정보 오류를 명시하고 유료 신규 연장으로 조용히 덮어쓰지 않는다.
- 정보상세: 실시간 재고 아님, 판매페이지 재등장 대리 신호, 변화 없으면 무발송, 최종 가격·상품 구성·재고는 판매처 기준.

## 검증 계약

390px 모바일과 1440px 데스크톱에서 줄바꿈/수평 넘침/primary action 하나/연결과 이동을 실제 브라우저로 확인한다. 순수 `AlertSettingsView` props fixture로 로그인·미연동·준비중·신청대기·입금안내·활성·만료·오류·로딩·수동권한 상태를 확인한다. fixture는 저장소 외부 검증 도구이며 운영 route/auth 우회를 넣지 않는다.

실제 검증 결과는 `docs/REVENUE_PILOT_PROGRESS.md`에 기록한다. build 성공이나 소스 검토만으로 UI 시각 검증 완료를 주장하지 않는다.
