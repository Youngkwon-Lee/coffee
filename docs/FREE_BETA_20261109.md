# Coffee 원두레이더 무료 베타 — 2026-11-09

## 목적과 범위

크롤러 원두 목록이 실제 사용자에게 쓸모가 있는지 먼저 검증한다. 초기 대상은 직접 초대받고 자발적으로 참여하는 약 5~10명의 홈카페 사용자다. 초대 링크는 `https://coffee-omega-lovat.vercel.app/onboarding`이다. 이 문서를 만들었다고 초대 메시지가 발송되거나 고객이 모집된 것은 아니다.

무료 베타에서 제공하는 경험:
- `/changes`: 최근 7일간 새로 확인된 원두·판매 목록 재등장·검증된 가격 인하 표시. 실제 신제품·재고 보장 아님
- `/beans`: 원두 이름·브랜드·향미·로스팅 등을 탐색·비교하고 판매처 상품 페이지로 이동
- `/my-beans`: Google 로그인 후 즐겨찾기한 원두를 저장·확인. 실제 사용자 로그인과 저장 후 재조회는 아직 별도로 확인해야 함

**무료 범위 밖:** 유료 결제, 실제 구매, 개인 Telegram 알림의 안정적 수신, 실시간 재고. 기존 유료 플래그와 SNS 보류 사항은 변경하지 않는다.

## 소규모 베타 진행 방식

1. 참가자 본인이 자발적으로 체험하고 로그인은 찜할 때만 진행. 지인에게 초대 링크를 공유할 경우 초대·응답을 별도로 확인한다.
2. 참가자에게 실제 구매를 요구하지 않는다. 판매처 상품 페이지에 들어가도 결제하지 않아도 된다.
3. 다음 3가지를 비식별 텍스트로 질문: 찾고 싶은 원두를 찾았는지, 찜 등록/재진입이 가능했는지, 개선할 점 한 가지.
4. 로그인/저장 오류가 보고되면 오류 유형과 재현 단계만 확인한다. 이메일, 비밀번호, 토큰, 계좌·주문 정보, 브라우저 프로필을 수집하지 않는다.
5. 이벤트 숫자는 공식 Vercel Web Analytics의 `coffee_changes_view`, `coffee_change_detail_open`, `coffee_bean_store_open`, `coffee_favorite_saved`로 확인한다. 사람 수나 매출이 아닌 사건 발생 건수다.

과거 운영자 테스트 이벤트는 실제 고객 데이터로 재분류하지 않는다. Vercel Analytics 페이지뷰/Custom Event는 수집이 허용된 익명 집계이며, 동일 인물의 복수 행동과 고유 방문자를 1:1 매핑하지 않는다. 불필요한 방문 테스트로 전환 KPI를 부풀리지 않는다.

## 후속 판단

사용자가 막힘 없이 기능을 완수하고 반복 사용 여부가 확인되기 전에는 유료 기능을 개방하거나 공개적으로 결제를 권유하지 않는다. 소규모 무료 베타에서 사용자 피드백과 브라우저별 문제를 우선 수집하고, 필요하면 기존 제품의 최소 수정을 한 뒤 해당 이력을 확인한다.

SNS 연동 문제, 추가 Firestore 컬렉션, 외부 폼, 새 예약/알림 자동화, 대량 마케팅 발송은 범위 밖이다.
